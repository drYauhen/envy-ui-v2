Hover Interaction

Hover over avatars to see the spread animation (app/website contexts only).

Hover behavior:

  • Hovered avatar scales up by 1.1x
  • Neighbors spread out by 12px for better visibility
  • Smooth transition with ease-out easing (200ms)
  • No animation in report context (print-friendly)

Component Architecture

Avatar Token Structure

  • Tokens: tokens/components/avatar.tokens.json
  • Contract: tokens/components/avatar.contract.json
  • Generated CSS: generated/css/components/avatar.tokens.css
  • Component CSS: src/ui/avatar.css

Avatar Group Token Structure

  • Tokens: tokens/components/avatar-group.tokens.json
  • Contract: tokens/components/avatar-group.contract.json
  • Generated CSS: generated/css/components/avatar-group.tokens.css
  • Component CSS: src/ui/avatar-group.css

Avatar Axes

  • data-eui-size: sm | md | lg
  • data-eui-role: lead (optional)

Avatar Slots

  • img: Profile image
  • .eui-avatar-initials: Fallback initials

Key Token Variables - Avatar

  • --eui-avatar-size-*-diameter
  • --eui-avatar-size-*-fontSize
  • --eui-avatar-colors-background-fallback
  • --eui-avatar-colors-text-fallback
  • --eui-avatar-border-color-*

Key Token Variables - Avatar Group

  • --eui-avatar-group-layout-overlap
  • --eui-avatar-group-layout-overlap-lead
  • --eui-avatar-group-layout-overlap-tight
  • --eui-avatar-group-layout-hover-spread
  • --eui-avatar-group-layout-hover-scale
  • --eui-avatar-group-layout-hover-duration
  • --eui-avatar-group-layout-hover-easing
  • --eui-avatar-group-counter-gap
