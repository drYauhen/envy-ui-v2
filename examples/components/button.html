Button Component

Button component following the canonical architecture pattern with token-driven styling.

Intents

Different button intents for various actions and contexts.

Primary

<button class="eui-button" data-eui-intent="primary" data-eui-size="md">Primary Button</button>

Secondary

<button class="eui-button" data-eui-intent="secondary" data-eui-size="md">Secondary Button</button>

Accent

<button class="eui-button" data-eui-intent="accent" data-eui-size="md">Accent Button</button>

Accent Finished

<button class="eui-button" data-eui-intent="accent-finished" data-eui-size="md">Finished Button</button>

Link

<button class="eui-button" data-eui-intent="link" data-eui-size="md">Link Button</button>

Sizes

Three size variants for different UI densities.

<button class="eui-button" data-eui-intent="primary" data-eui-size="sm">Small</button>
<button class="eui-button" data-eui-intent="primary" data-eui-size="md">Medium</button>
<button class="eui-button" data-eui-intent="primary" data-eui-size="lg">Large</button>

Shapes

Different border radius variations for various design contexts.

Default

<button class="eui-button" data-eui-shape="default">Default Shape</button>

Round

<button class="eui-button" data-eui-shape="round">Round Corners</button>

Circle (Icon Only)

<button class="eui-button" data-eui-shape="circle" aria-label="Add">+</button>

With Icon Slots

Buttons support start and end icon slots for enhanced communication.

<button class="eui-button" data-eui-intent="primary">
<span data-eui-slot="start-icon">←</span>
<span data-eui-slot="label">Back</span>
</button>

States

Interactive states demonstrate button behavior.

Component Architecture

Token Structure

  • Tokens: tokens/components/button.tokens.json
  • Contract: tokens/components/button.contract.json
  • Generated CSS: generated/css/components/button.tokens.css
  • Component CSS: src/ui/button.css

Axes (Data Attributes)

  • data-eui-intent: primary | secondary | accent | accent-finished | link
  • data-eui-size: sm | md | lg
  • data-eui-shape: default | round | circle

Slots

  • data-eui-slot="start-icon": Icon before label
  • data-eui-slot="label": Button text
  • data-eui-slot="end-icon": Icon after label

Key Token Variables

  • --eui-button-colors-background
  • --eui-button-colors-text
  • --eui-button-colors-border
  • --eui-button-size-height
  • --eui-button-focus-ring-color
  • --eui-button-layout-whiteSpace
