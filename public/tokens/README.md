# Design Tokens

This directory contains the canonical token sources for Envy UI.

## Canonical Structure

```
tokens/
  primitives/         # Literal source of truth
  contexts/
    app/
      raw/
      semantics/
      themes/
    website/
      raw/
      semantics/
      themes/
    report/
      raw/
      semantics/
      themes/
  components/         # Component tokens + contracts
  knowledge/          # Workflow notes (non-canonical)
  legacy/             # Deprecated/quarantined artifacts
```

The old `web` context name is deprecated and has been renamed to `website`. Legacy artifacts may still exist under `tokens/legacy/contexts/web`. The website context may temporarily inherit app semantics until website-specific tokens are added.

## Resolution Order

Primitives → Raw → Semantics → Themes → Components

Component tokens are semantic-only and must not reference primitives or literals directly.

## Notes

- Canonical CSS is generated by `scripts/generate-canonical-css.mjs` (primitives/contexts/themes).
- Component token CSS is generated by `scripts/generate-component-css.mjs`.
