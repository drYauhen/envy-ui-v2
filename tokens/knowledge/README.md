# Knowledge / Workflow Directory

This directory contains token-related content that supports development workflows but is not part of the canonical render graph.

## Contents

### `components/`
Component contracts and specifications. These are human-readable descriptions of component token requirements, not the actual render values.

### `report/`
Reporting and documentation data for token analysis and visualization.

### `storybook/`
Storybook-specific themes and configurations.

### `website/`
Website-specific token configurations and themes.

## Purpose

These files are preserved for:
- Documentation and specification purposes
- Workflow tooling and development aids
- Reference implementations
- Future architectural exploration

They are **excluded from render builds** to maintain clean canonical boundaries.
