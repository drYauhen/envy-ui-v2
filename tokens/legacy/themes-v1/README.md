# Legacy Themes v1

This directory contains the old flat theme structure that was replaced by the contextual theme architecture.

## Original Structure
- `app/` - App-specific themes
- `report/` - Report-specific themes
- `website/` - Website-specific themes

## Why Legacy
This structure was replaced by `tokens/contexts/**/themes/` which provides:
- Better separation per context
- Cleaner organization
- More scalable architecture

## Status
Preserved for historical reference. Not used in current render pipeline.
